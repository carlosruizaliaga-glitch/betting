# Betting 🟢

Registro de apuestas deportivas (sustituye la hoja "Betting"). App web instalable (PWA): funciona sin conexión y sincroniza con la nube (Supabase, proyecto "Split Carlis", tablas `bt_`).

## Uso rápido
- **Apuntar una apuesta:** botón verde **+** → escribe selección y cuota → toca un **nivel 1–10** (ves los € al momento) → **GUARDAR**. Casa, deporte, tipo, tipster y fecha ya vienen puestos.
- **Combinada:** en el formulario, **+ SELECCIÓN** y pon la cuota de cada una.
- **Cerrarla:** en INICIO, en la tarjeta pendiente, toca **GANADA · PERDIDA · NULA**. Para medio ganada, medio perdida o cash out, toca **···**.
- **Stake por nivel:** nivel × unidad (1 % por defecto) × disponible (depósitos + beneficio − lo que está en juego). Igual que la hoja.
- **Caja:** INICIO → CAJA para depósitos, retiradas, bonos y apuestas gratis.
- **Copia:** AJUSTES → Copia de seguridad (CSV para Excel o copia completa).

## Nota
El plan gratuito de Supabase pausa el proyecto tras 1 semana sin uso. Si ocurre: supabase.com → proyecto Split Carlis → "Restore". La app sigue funcionando en el móvil y sube los cambios al reactivarlo.
